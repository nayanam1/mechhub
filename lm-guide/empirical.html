경험식 대조

기존57조건과 Gr 추가시험14조건입니다. 정속 PT=0의 PR 부호는 확인한 입력만 적용하며 미시험 값은 보간하지 않습니다. BS60 전환구간을100배 좁혔고, BS100 Gr5.69에서 +|R| 후보식 반례를 확인했습니다. 이번 자료로 보정한 재현 대조입니다. m30 영점 PT 차이 0.1005 N과 수명 기준 초과 항목을 그대로 표시합니다.

하중 대조 허용차 ±0.1 N은 이번 모델의 대조 기준입니다. 물리적 오차 보증이나 PDF 반올림만의 오차로 해석하지 않습니다.

계산 근거와 적용 범위

TRACEABILITY
자동 PR·PT · 후보식

Theta 응답 모델 · BS별 계수표 / HSR10R 전용

W=m·g, g=9.80665 m/s², a=[+V/(1000·tn), 0, −V/(1000·tn)]
R=kR·W·(Gr−5.7)/2, D=kP·m·a·(Br+Gr)
PR₁=s₁·R+D, PR₂=s₂·R−D
PT₁=−W/2 − kP·[W·(BS/2−Ga)−m·a·(Bt−Gt)], PT₂=−W−PT₁
kP(BS): 31.6→0.05021 / 40→0.02902 / 60→≈0.016677009192 / 100→0.010000 mm⁻¹
kR=0.235 mm⁻¹, sᵢ=sign(정속 PTᵢ), 검증한 영점 입력만 별도 분기
Ga₂*=BS/2−1/(2·kP), Ga₁*=BS/2+1/(2·kP)

kP는 각 BS 기준 PR 가감속 차에서 추정한 경험 응답계수입니다. BS60은 No.1 전환 시험을 반영해 전환 확인구간의 중앙값 Ga59.981395에 맞춰 kP≈0.016677009192로 보정했습니다. 보정 자료를 이용한 재현 대조이며 독립 검증이 아닙니다. 제조사 공개 간격 일반식은 미확인으로, 표 사이를 보간하지 않습니다. kR=0.235는 구형 HSR10 KC와 일치합니다. Gr 기준 오프셋 5.7 mm와 정속 PT 부호 분기는 공식 출력에서 추정한 모델이며, 제조사 공식 좌표·볼 열 해법으로 확정한 것은 아닙니다. PR에는 롤 모멘트 환산 성분이 포함되므로 두 블록 PR의 합을 0으로 강제하지 않습니다. ΣPT=−W는 유지합니다.

검증 범위: 기존 7조건 + 질량 7.5/30 kg, Gr 0/−13 mm, Ga −10/+10/+5/+6 mm, Gt ±5 mm의 단일변수 10조건. Ga=5와 6 사이에서 No.2 정속 PT 부호 및 롤 방향이 전환됨을 확인했습니다. 복합 A: m12/Gr20/Gt−3/Br−8/Bt7/Ga5·6, B: m22/Gr−6/Gt2/Br16/Bt−4/Ga5·6, C: m9/Gr8/Gt4/Br−15/Bt−6/Ga25·26을 추가 확인했습니다. BS40에서 Ga2/3 및37/38, BS60과100에서 Ga−1/+1을 추가 대조했습니다. BS60 No.1 전환은 Ga59.98139~59.98140 mm 사이로 확인했으며 내부 구간은 계산을 차단합니다. BS100 No.1 Ga99.99/100/100.01과 Ga100의 m30·Gr0을 대조했습니다. Ga100·Gr0에서는 R가 음수여도 정속 PR₁가 +98.6 N이므로 단순 영점 s=+1은 틀립니다. 확인한 영점 입력 조합만 별도 분기를 적용합니다. 기존 Ga0 No.2 예외도 유지합니다. BS100·Ga100에서 Gr−13/5.69/5.7/5.71/26 mm를 추가 시험했습니다. Gr5.69에서 정속 PR₁=−0.2 N으로 +|R| 일반식의 반례가 나왔습니다. Gr5.7은0 N으로 방향 식별 불가입니다. 새 조건도 관측한 조합만 분기표에 추가하며 Gr 보간은 하지 않습니다. 일반 영점 규칙은 미확정입니다. BS60 미확정 구간의 폭은0.00001 mm이며 물리적 설계 정밀도를 뜻하지 않습니다. 나머지 조합·정확한 전환점·표에 없는 BS·다른 모델은 미검증입니다.

공개식 · 단위 검산

운동조건과 수명 환산

a = V / (1000·tn)
가속거리 = V·tn / 2
L = 50·[C / (fw·Pm)]³
Lh = L·10⁶ / (2·ST·n)

볼 타입, C의 50 km 기준, n은 왕복/시간. 온도·경도·접촉 등 추가 보정계수는 1로 가정합니다.

방향 채널과 가속 안전율

E = max(sR·PR, 0) + max(sT·PT, 0)
Pm = ∛(ΣE³·거리 / ST)
4개 부호 채널 중 Pm 최대값 선택

실제 볼 열 번호나 개별 볼 접촉하중을 계산하지 않습니다. H2가 감속 PR을 참조하는 물리적 근거는 미확인입니다.
모멘트 환산과 미검증 항목

공개식 P=K·M (M: N·mm, K: mm⁻¹). 구형 HSR10 계수: 단일 KA·KB=0.309, 밀착 2블록 KA·KB=0.0533, KC=0.235. 현재 예제의 PR·PT에 추가로 적용하면 중복 계산될 수 있어 자동 가산하지 않습니다. 임의 간격의 블록에 밀착 계수를 대입하지 않습니다.

미검증: 일반 형상→블록 반력, 미등록 복합 조건의 민감도, 실제 볼 열 접촉분포, 예압·강성·장착오차, 다른 제품·배치에 대한 일반화. 계산조건을 만족하는 제품 검색은 후속 단계입니다.
