# MechHub

기구설계 가선정 및 계산 플랫폼.

운영: https://mechhub.nayanam.synology.me/

- LM Guide: 수평·수직·벽면의 1레일×2블록 및 2레일×레일당 2·3·4블록을 NSK 카탈로그 이상화 공식으로 참고 계산. 2레일 힘 조합 정적 안전율을 제공하며, 1레일 힘+롤 종합 안전율은 미확정. THK와 미지원 배치는 계산·추천에서 제외.
- 볼스크류: THK BNK 4구성. 예압형 G0 수명 미검증, G2 조건부 후보.
- 모터: 공통 프로파일 기반 Panasonic MINAS A6 MDMF 200/400V 8형번군. 후보별 관성 재계산, RMS·보수 토크속도 곡선·과부하 보호시간 검토. 반복 열·회생·기계계통 최종 검증은 별도.
- 소형 모터: MSMF 100/200/400W 단순 직결 검토도 별도 범위로 보존한다.
- 택타임: 등가속도 삼각형·사다리꼴 이동과 대칭 왕복 시간.
- 운전 프로파일: 접근·가압·유지·복귀 구간 및 리드별 비교.

제품 가선정용 도구이다. 최종 설계자는 제조사 공식 선정 프로그램에서 동일 조건으로 확인한다.
공식 계산, 툴 관찰, 미확정 항목을 구분하며 종합 적합 판정을 제공하지 않는다.

## 시스템 책임

계산 로직 원본은 MechHub에서 관리한다. Catalog Library는 기술자료를 제공한다.
n8n은 별도 채팅에서 API 또는 합의된 데이터 인터페이스로 연동한다.
이 저장소에서 n8n 워크플로를 관리하지 않는다.

## 운영

정적 HTML/JavaScript이므로 index.html 및 하위 자산을 동일 경로 구조로 제공한다.
release.json은 배포 파일별 SHA256과 크기를 기록한다.
common.css 및 sidebar.js는 기존 배포 검사의 호환성 진입 파일이다.
배포 전 사이트를 백업하며 구형 포털은 Git 이력에서 복구할 수 있다.

MINAS 곡선은 공식 PDF를 읽어 만든 보수 근사이며 OEM 보증 수치표가 아니다. 보호시간 검토는 반복 피크 허용시간이 아니다. 가압 거리/시간, 질량, 복귀/유지/대기, 실제 전원 등은 미정으로 시작한다.
