Theta 형상 → 하중 근거 검토

2026-10-16 · 계산 화면 · 기존71조건 Pm 대조 · 근거·수치 JSON (공개 미포함)

판정: 일부 도출, kP와5.7 mm는 미확정. 좌표의 팔길이와 강체 평형은 정리했다. 임의 BS에서의 접촉 등가하중과 하중 중심 높이는 검토한 자료에서 공식 근거를 찾지 못했다. 두 값을 공식 상수로 승격하거나 1/BS로 대체하지 않았다. 이번 검토는 새 THK 실행값이 아니라 카탈로그·도면 검토다.

1. 공식 입력 도면에서 확인한 좌표

2026-10-16 로그인된 THK 결과 화면 HSR10R / 벽면 / 1레일2블록에서 표시 자산을 보존했다. 질량 도면 원본 · 추력 도면 원본 (로그인 필요 가능). 이 그림은 좌표 정의를 제공하며 하중 중심 h의 수치 치수는 제공하지 않는다.

2. 형상→강체 평형: 도출 가능한 부분

자체 좌표: x=No.1→No.2, y=취부면에서 추력 쪽, z=Gt/Bt 방향. 질량 위치는 (Ga,−Gr,Gt), 추력 위치는 (0,Br,Bt). 가속 구간의 관성력은 (−ma,0,0), 추력은 (+ma,0,0), 중력은 (0,0,−W). 추가 외력·마찰·회전 가속도는 없는 배치다.

W = m·9.80665 N, a = (V/1000)/tn m/s²
취부면 원점에서 ΣM = Σ(r × F):
Mx = W·Gr
My = W·Ga + m·a·(Bt−Gt)
Mz = −m·a·(Br+Gr)                     [N·mm]

블록 중심을 점지지로 이상화한 각 블록 부하 합력:
D1 = −Mz/BS; D2 = Mz/BS
T1 = −W + My/BS; T2 = −My/BS
ΣD=0, ΣT=−W, BS·D2=Mz, −BS·T2=My

하중 중심이 취부면에서 질량 쪽으로 h 떨어져 있다면:
잔여 롤 모멘트 Mc = W·(Gr−h)
→ h가 없으면 Mc는 미확정. 두 블록에 Mc/2를 배분하는 것도 별도의 가정.

여기서 D/T는 블록이 받는 합력이며 지지대가 테이블에 가하는 반력은 반대 부호다. 이 평형식은 THK의 임의 BS 접촉 해석식이라고 주장하지 않는다. 블록 내부의 끝단 볼 집중하중·예압·강성 및 잔여 모멘트를 반영하지 않아 이 합력을 곧바로 PE/Pm에 넣지 않는다.

3. 모멘트 등가계수 K와 kP는 같은가?

THK A1-40~42는 모멘트에 의한 불균일 볼 하중을 등가하중 P=K·M으로 환산하고, K=C0/M 허용값 관계를 설명한다. 계수 정의의 KAR2/KAL2/KB2는 두 블록을 밀착한 경우다. 임의의 BS를 넣는 함수는 검토한 구간에 없다.

구형 THK PDF69쪽 / 인쇄57 (공개 미포함) HSR10: KAR1=KAL1=KB1=0.309, KAR2=KAL2=KB2=0.0533, KCR=KCL=0.235 mm⁻¹. 이 표의 밀착 쌍 계수를 Theta BS31.6의 kP=0.05021과 같다고 둘 수 없다. PDF242쪽 (공개 미포함) 정격의 비 C0/MA1=0.310569106, C0/MA2=0.053351955, C0/MC=0.235802469 mm⁻¹ 역시 표의 반올림값과 완전히 같지 않다. 개정·반올림 출처를 유지한다.

차이는 곧 평형 위반의 증거가 아니다. 접촉 등가하중은 단순 합력과 정의가 다르다. BS100에서 수치가 같다는 이유만으로 다른 BS에도 kP=1/BS를 적용하지 않는다. BS60 값은 관측 전환점에서 역산한 후보이고, 공식 계수로 분류하지 않는다.

4. 5.7 mm를 도면 치수로 확정할 수 있는가?

구형 PDF264~265쪽 / 인쇄252~253 (공개 미포함) HSR10R-M: 조립높이 M=13, 폭 W=20, 블록 길이 L=31, 본체 길이 L1=20.1, K=10.8, 레일 높이 M1=7 mm. 검토한 도면에는 하중 중심 높이5.7 mm가 명시되어 있지 않다. 조립높이·레일높이·급유부 치수만으로 접촉 중심 또는 롤 회전 중심을 확정하지 않는다. 축척 그림에서 픽셀 비율을 재어 치수로 사용하지 않았다.

툴 모델 HSR10R와 도면 HSR10R-M, 구형/현행 XR의 정격·치수 개정 일치도 별도 확인이 필요하다. 5.7은 현재 출력 재현에서 추정된 취부면→유효 기준점으로만 남긴다. 도면 원점 Gr=0과 후보 롤 영점 Gr=5.7은 서로 다른 개념이다.

5. 모듈 수정과 검증

theta-geometry.js에 합력·모멘트·점지지 분배를 독립 추가했다. h 기본값은 없으며, 미입력 시 잔여 롤 모멘트는 null이다. 화면에서 h와 도면 근거를 입력하면 별도 평형 표와 JSON에 기록되지만 THK 공식 치수로 인정하지 않는다. 기존 후보 모듈은 kP·5.7·롤 반분의 상태를 내보내며 기존71조건의 재현 경로를 보존한다.

다음 확인에 필요한 자료: 해당 개정 HSR10R의 하중 중심 치수 또는 THK의 기준점 설명, 임의 블록 간격의 접촉/등가 모멘트 배분 절차. 이 자료 없이 수치 일치만으로 공식 도출 완료라고 판정하지 않는다.

6. 본회원 로그인 후 기술자료·CAD 후속 조사

공식 도출 상태: 미완료. 이번 조사에서 새 kP 또는 기준점을 툴 출력에 맞춰 추정하지 않았다. 수치 상수와 기존71조건 재현 계산은 변경하지 않았다. 본회원 기술자료2개(9쪽+5쪽)를 열람했다. 구형 HSR10R 원본 CAD 파일은 확보하지 못했으며, CAD 내부 형상을 검사했다고 주장하지 않는다.

5.7 mm와 1/KCR를 혼동하지 않는다

KCR = C0 / Mc_allow [1/mm]
1/KCR = Mc_allow / C0 [mm] : 정격의 비로 얻은 등가 팔길이
h [mm] : 레일 취부면에서 정의된 하중 중심까지의 좌표
→ 단위가 같아도 같은 물리량이 아니다.
기존 KCR=0.235이면 1/KCR≈4.255319 mm. h=5.7의 도출 근거가 되지 않는다.

하중 중심은 외형 중심·질량 중심·급유구 중심과 구분해야 한다. 접촉점 위치와 접촉각을 알아도 실제 해석 기준점 및 예압·강성에 따른 배분 정의가 별도로 필요할 수 있다. CAD에 보이는 명목 홈 형상만으로 툴의 유효 기준점이 입증되는 것은 아니다.

BS만으로 kP를 확정할 수 없는 이유

레이디얼 합력 분배의 평형:
D1 + D2 = 0
BS·D2 + mz1 + mz2 = Mz
mz1,mz2 : 각 블록 내부에서 부담하는 국소 모멘트

mz1=mz2=0을 가정하면 D2=Mz/BS.
하지만 국소 모멘트 배분을 허용하면 접촉·강성 조건 없이 D2는 유일하지 않다.
더구나 kP의 대상 P가 볼 부하의 등가량이면 합력 D와 동일하다고 둘 수 없다.

이는 자체 정역학 설명이며 THK 내부 알고리즘을 역산한 식이 아니다. kP=1/BS를 일반 THK식으로 승격하지 않고, 기존 표를 보간하거나 단면 치수로 새 경험식을 만들지 않았다. K=C0/M 관계 역시 정격값의 환산 관계이며 임의 BS 배분 함수까지 결정하지 않는다.

위 질문은 검토용이며 THK에 전송하지 않았다. 본회원 기술자료 열람은 완료했다. 현재 남은 것은 정확한 구형 도면 개정·하중 중심 정의·비밀착 블록의 접촉 등가하중 배분 절차에 대한 제조사 근거다. 출처별 접근 상태·근거 분류 JSON (공개 미포함)
