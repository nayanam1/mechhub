LM 배치별 공식 검증과 적용 범위

계산 범위

수평·수직·벽면의 1레일×2블록, 2레일×레일당 2·3·4블록. NSK PU·PE 12개 제품의 C50·C0·εr 데이터에 연결합니다. THK 제품, 천장, 1블록 배치와 1레일 3·4블록은 계산하지 않습니다.

정량 검증은 카탈로그 식, 독립 힘·모멘트 평형 및 기존 Theta 결과와의 대조입니다. 새 배치를 제조사 공식 웹 툴과 대조했다는 의미는 아닙니다. 종합 선정 합격은 반환하지 않습니다.

NSK 공식 E3162 카탈로그 원문

A35–38 표 2.2 패턴 2/4/5/6: 하중 배분 / A39–41: 동등가·평균하중 / A43: 수명 / A44: 정적 안전율.

좌표와 가정

공통 좌표 X는 레일 길이, +Y는 지지 기준면의 법선, +Z는 No.1에서 No.2 레일 방향입니다. O1은 No.1 이상화 지지점, 블록 번호는 첫 레일의 +X 순서 후 다음 레일 순서입니다. 수직에서 +X는 위쪽입니다. 왕로 기본은 −X이며 복로는 반대입니다.

중력 [gx,gy,gz] m/s²: 수평 [0,−9.80665,0], 벽면 [0,0,−9.80665], 수직 [−9.80665,0,0]. Fr 양수는 −Y 방향, Fs 양수는 −Z 방향입니다. 카탈로그 도면은 중심 기준·번호 방향이 다르므로 원점 이동과 축/부호 변환을 적용합니다.

동일 제품·동일 강성·평행 레일·강체 테이블·PC/ZT의 이상화 모델입니다. 예압과 취부 오차의 재분배, 실제 접촉 중심 보정, 가공력·케이블 반력, 볼트 강도는 미반영입니다. Y 치수는 동일 지지 기준면에서 측정해야 하며, 기존 Theta의 기준을 유지합니다. THK의 경험적 5.7mm와 kP는 사용하지 않습니다.

형상 → 블록 하중

N = 레일 수 × 레일당 블록 수. 블록군 중심 cx=(b−1)BS/2, cz=(r−1)RS/2. 아래 x,z는 중심에서 잰 무게중심 좌표, xi,zi는 중심에서 잰 블록 좌표입니다. y는 Y 기준면에서 잽니다.

Q = m(ax − gx)                    [구동력, N]
Wy = m gy, Wz = m gz              [횡방향 중력, N]
Mx = y Wz − z Wy
My = (Bz − Gz) Q − x Wz
Mz = x Wy + (Gy − By) Q           [중심 기준 외력 모멘트, N·mm]
Sx = Σ xi², Sz = Σ zi²            [모든 블록에 대해 합산]

2레일: Fy_i = Wy/N + Mz xi/Sx − Mx zi/Sz
       Fz_i = Wz/N − My xi/Sx, Mr_i = 0
1레일: Fy_i = Wy/2 + Mz xi/Sx
       Fz_i = Wz/2 − My xi/Sx, Mr_i = Mx/2
Fr_i = −Fy_i, Fs_i = −Fz_i

2레일·2블록은 표 2.2 패턴4와 동일합니다. 3블록은 패턴5의 l=2BS, 4블록은 패턴6의 l=BS·l′=3BS로 변환합니다. 모든 블록에 모멘트를 다시 추가하지 않습니다. 1레일에만 남는 로컬 롤 모멘트를 εr로 변환합니다.

하중 → 동등가·수명·정적 검토

PU/PE: A = [|Fr|, |Fs|, εr |Mr| / 1000]   (εr: 1/m)
Fe = (Σ A + max A) / 2
Fm = [Σ(Fe³ × 구간 거리) / Σ 거리]^(1/3)
L50 = 50 × [C50 / (fw × Fm)]³   km
시간 수명 = L50 × 10^6 / (2 × 스트로크 × 왕복 빈도)
힘만 작용: P0 = max구간(|Fr| + |Fs|), fs = C0/P0

왕로·복로의 가속·정속·감속 6구간을 포함합니다. 거리 0인 구간은 하중 노출에서 제외합니다. 정지 시간의 피로는 거리 평균에 들어가지 않으며, 기동 충격·jerk는 미검토입니다. 가속도 0은 정속 이상화 입력입니다.

2레일의 이상화 배분식에는 로컬 모멘트가 없으므로 A44의 힘 조합 fs가 적용됩니다. 1레일의 힘+롤 조합 fs는 공식 근거 미확정으로 null을 반환합니다. 힘만 fs와 롤만 fs를 합산하거나 최솟값을 종합 fs로 사용하지 않습니다.

A44의 일반 산업용 볼 가이드 지침: 통상 fs 1–2, 진동·충격 fs 1.5–3. 실제 요구 기준과 충격 유무는 설계자가 정해야 합니다. 최소 블록 수명을 시스템 참고 수명으로 표시합니다. 무하중 ∞는 입력 모델의 결과로 실제 무한 수명 보장이 아닙니다.

독립 검증 결과

480개 형상에서 힘 2성분과 모멘트 3성분의 평형 확인. 144개 제품/배치 조합 계산. 패턴4·5·6의 모멘트 계수 직접 대조, 왕로 방향 반전 시 대칭 사이클의 Fm 불변, 중력 중앙·편심·수직 중력 구동력·레일 롤 분배와 입력 오류 차단 확인.

기존 Theta의 왕로 Fr·Fs·Mr·Fe와 Fm·최댓값 회귀 일치. 과거 NSK 툴의 수치 출력 사례는 0.001N 이내. Theta 15kg의 공식 툴 NG 관찰은 같은 벽면·1레일·2블록 조건에만 표시합니다.
