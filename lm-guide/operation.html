동작을 나누면, 선정 조건이 명확해집니다.

시간·볼스크류·모터·LM이 한 프로파일을 공유합니다. 구간별 시간과 리드별 회전수·토크를 비교합니다. 실제 제품 선정에는 추가 조건과 카탈로그 검증이 필요합니다.

01 편도 이동과 끝부분 가압

0.6초 = 접근 이동 + 가압 이동입니다. 도착 후 유지·복귀는 포함하지 않습니다. 가속과 감속은 각각 구간 시간의 25%로 시작하며, 확인할 파형 가정입니다. 50%는 삼각 속도입니다.

전체 사이클을 알 때 추가 입력

02 시간 계산

계산 모델과 가정

    구간 속도 v = 거리 / [시간 × (1 − 가속시간비율)], 가속도 a = v / 가속시간. 구간 경계의 속도는 0입니다. 힘이 동시에 작용하는 시점은 별도 하중 프로파일이 필요합니다.

    03 볼스크류·모터 · 리드별 비교

    초기 감속비1·전달계 효율1은 직결·전달 손실 무시 가정입니다. 스크류 효율은 별도 입력하며 자동 가정하지 않습니다. 회전 관성에는 스크류·커플링·풀리 등을 해당 축 기준으로 포함하세요.

    회전수는 최고속도 기준입니다. 이상 토크(η=1)는 이론 최소값, 가압 부하 토크는 가압력 성분만입니다. 마지막 열은 누락 조건이 모두 입력된 경우의 보수적 크기 상한이며 실제 피크·RMS·모터 정격 토크가 아닙니다. 숫자가 작다는 이유로 적합 순위를 매기지 않습니다.

    선정에 필요한 추가 입력과 검토
      계산식·가정과 근거

      n = 60v/리드, T = F·리드/(2πη), 모터 n = 스크류 n × 감속비. 모터 부하 토크 = 스크류 부하 토크/(감속비 × 전달 효율). 가압 구간 밖에는 가압력 1tonf를 적용하지 않습니다.

        THK 회전 토크 계산 · THK 모터 선정 기준

        04 전체 사이클 RMS · 모터 수치 제한 비교

        위의 ‘전체 사이클을 알 때 추가 입력’에서 유지·복귀·기타 대기 시간을 입력하세요. 없는 정지 구간은 0을 명시합니다. 가압력 모델은 실제 공정 확인이 필요한 계산 가정입니다.

        +축은 전진 방향입니다. 복귀 요구 축력은 질량·중력·가이드 저항 이외의 추가 성분만 입력하며, 복귀를 방해하는 하중은 음수입니다. 유지·대기 토크는 모터축 값 전체를 입력합니다. 정지 시간 0이면 해당 토크는 필요 없습니다.

        RMS ≤ 정격, 최대 |토크| ≤ 최대 토크, 최대 |rpm| ≤ 최대 회전수를 각각 비교합니다. 정격 회전수 초과는 즉시 탈락이 아니며 해당 속도의 허용 토크 곡선이 필요합니다. 세 수치가 통과해도 피크 지속시간·열·드라이버·제동 및 기계부 검증 전에는 최종 적합이 아닙니다.

        RMS 계산·모터 비교에 필요한 추가 입력
          리드별 구간 토크 이력
          RMS 모델과 계산 가정

            선형 구간 T₀→T₁의 제곱 적분 = Δt(T₀²+T₀T₁+T₁²)/3. RMS = √(각 구간 제곱 적분 합 / 전체 시간). 유지·대기를 포함합니다.
