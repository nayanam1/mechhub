    8. 요소설계 & 계산 🧊 Chiller 배관 부하 검토 계산기

    📌
    TW161 Chiller 배관 부하 검토 자료의 계산 절차(발열량→필요유량→유속/내경→레이놀즈수/마찰계수→마찰압력손실→펌프 차압여유 판정)를 그대로 따르는 순차 계산기입니다. 각 단계 결과는 자동으로 다음 단계 입력값에 반영되며, 필요 시 직접 수정도 가능합니다. 쿨란트 물성치는 Capchem HTF-7500 / 3M Novec-7500의 실측 물성표(-80~130℃)를 보간하여 사용합니다.

    1쿨란트 물성치 조회 (온도 보간)

    물성표(HTF-7500 / Novec-7500)의 실측 데이터 구간을 선형 보간하여 해당 온도의 밀도·비열·동점도·증기압·열전도율을 산출합니다. [계산 적용] 클릭 시 아래 2·4단계의 물성 입력값에 자동 반영됩니다.
