공식 집계

THK 등가하중 → Pm → 수명

홈별 부하 가능 방향과 거리 가중 3승 평균을 적용합니다. fw는 수명 계산에 한 번 반영합니다.

Theta 하중 후보

형상 → 각 홈의 하중

BS별 kP와 Gr 원점5.7 mm는 아직 경험적 근거입니다. 부호 조회표·Gr 경계값 특례는 사용하지 않습니다.

과거 재현 모델

공식 계산과 분리

기존 모델과 부호 조회표는 과거 계산 화면에 보존했습니다. 현재 계산에는 사용하지 않습니다.

입력조건

초기 PE는 Theta 후보에서 복사했습니다. 직접 입력 모드 자체가 하중의 공식성을 보증하지 않습니다.

계산 상태

fH=fT=fC=1, C50 기준의 진단 계산값입니다. 전체 선정식·단거리 수명 적용성이 검증된 최종 선정값이라는 뜻은 아닙니다. 구형 가속 H2 특례는 사용하지 않습니다.

형상 → 힘·모멘트 평형 확인

THK 입력 도면으로 확인한 좌표 관계를 사용합니다. 점지지 반력과 홈 접촉 등가하중은 다릅니다. 이 표의 값을 수명 계산에 자동 전달하지 않습니다.

h 미입력 시 롤 모멘트는 미확정입니다. 후보 모드의 5.7 mm와 별도이며, 입력해도 THK 공인 치수로 인정하지 않습니다. 도면·계수·전개식 검토 ↗

블록별 Pm 대조

PDF의 fw 포함 Pm은 fw로 나누어 대조합니다. 입력을 바꾸면 일치 판정을 해제합니다.

재현 비교 기준: Pm ±0.15 N, 수명 ±0.5%. 설계 오차 보증이 아닙니다.

각 홈을 먼저 계산합니다

각 홈의 세 구간을 평균한 뒤 가장 큰 Pm을 선택합니다. 후보 PRq와 THK 표시 PR은 동일 정의로 단정하지 않습니다.

Pm 차이가 생겼던 위치

롤 모멘트가 있으면 반대쪽 홈의 레이디얼 성분이 달라집니다. 과거 코드는 하나의 표시 PR을 네 방향에 공통으로 사용했습니다.

하중 후보: PRq = D + st·R
공식 집계: PEq = max(sr·PRq, 0) + max(st·PT, 0)
Pm,q = [Σ(PEq³ × 구간거리) / 전체거리]^(1/3)
Pm = 모든 홈의 Pm,q 중 최대값

Gr5.55 · No.1: 기존 fw·Pm 13.831838 N → 수정 12.462846 N → THK 12.5 N. 전개식과71조건 대조

NSK는 제품 계열별로 구분합니다

NSK NH/NS의 접촉각50°·모델별 동등가계수와 THK HSR의 식은 교환하지 않습니다. Theta 수치 대조는 THK 사례이며, HSR 정격으로 NSK 제품의 수명을 계산하지 않습니다.

NH/NS: Fse=|Fs|tan50°, Fre/p/y=εr/p/y·|Mr/p/y|, Fe=½[ΣF+max(F)]. ε:1/m, M:N·m.
